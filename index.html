Open tools

LiDAR / laser rangefinder UART decoder

Paste a hex dump or connect a module over WebSerial. The decoder detects the protocol and baud rate, converts every frame to metres and flags checksum errors. Profiles cover Benewake (TFmini, TF-Luna, TF02-Pro, TF03), LightWare, Chengdu JRT, Nooploop TOFSense, DFRobot SEN0366 and ERDI modules.

Open in browser Source on GitHub Python: pip install lrf-uart-decoder

Laser rangefinder and LiDAR module database

A sortable comparison of modules from many makers by range, wavelength (905 nm / 1535 nm), accuracy, update rate, interface, weight, size and public price, with the manufacturer source URL and capture date for every row. Download it as CSV or JSON.

Drivers

  • Python: pip install erdi-lrf (source)
  • Arduino and PlatformIO: ErdiLRF (Arduino Library Manager: ErdiLRF)
  • ROS 2: erdi_lrf_driver (sensor_msgs/Range)
  • MicroPython on ESP32: erdi-lrf-esp32-micropython
  • CircuitPython: CircuitPython_ERDI_LRF (in the CircuitPython Community Bundle)
  • ESPHome and Home Assistant: erdi-lrf-home-assistant
  • STM32 HAL: erdi-lrf-stm32-hal
  • ArduPilot: serial driver submitted upstream in ArduPilot/ardupilot#34983
