# erditech.github.io

Source of <https://erditech.github.io/>, the index of ERDI TECH's open tools for laser rangefinder and single-point LiDAR modules:

- [LiDAR / laser rangefinder UART decoder](https://erditech.github.io/lrf-uart-protocol-decoder/) ([source](https://github.com/ErdiTech/lrf-uart-protocol-decoder))
- [Laser rangefinder and LiDAR module database](https://erditech.github.io/laser-rangefinder-module-database/) ([source](https://github.com/ErdiTech/laser-rangefinder-module-database))

This repository also holds the site-wide `robots.txt`, `sitemap.xml` and `llms.txt`.

Maintained by [ERDI TECH LTD](https://erdilrf.com/).
