# erditech.com

Source of <https://erditech.com/>, the brand home of ERDI TECH LTD (ErdiTech) and the index of its open tools for laser rangefinder and single-point LiDAR modules:

- [LiDAR / laser rangefinder UART decoder](https://erditech.com/lrf-uart-protocol-decoder/) ([source](https://github.com/ErdiTech/lrf-uart-protocol-decoder))
- [Laser rangefinder and LiDAR module database](https://erditech.com/laser-rangefinder-module-database/) ([source](https://github.com/ErdiTech/laser-rangefinder-module-database))

ERDI TECH laser rangefinder modules (ERDILRF): catalog, prices and datasheets at <https://erdilrf.com/>.

This repository also holds the site-wide `robots.txt`, `sitemap.xml`, `llms.txt` and `404.html`, and the `CNAME` file for the custom domain. The old address <https://erditech.github.io/> redirects here.
